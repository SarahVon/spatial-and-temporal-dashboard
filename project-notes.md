# Project notes

This portfolio dashboard compares average surface temperatures across world regions from 1901–2016. It combines a choropleth map, a time-series chart with a 1960–1990 reference average, and a monthly temperature-difference table. The final design emphasizes comparisons between 30-year averages and is published as a static image rather than an interactive dashboard.

Source provenance: World Bank Group Climate Change Knowledge Portal. See `README.md` for limitations and reuse guidance.
